# ✈️ High Cloud Airlines — Performance Analysis

## 📌 Project Overview

High Cloud Airlines Performance Analysis is an institute-guided group project focused on analysing airline operational data using Excel, MySQL, Tableau and Power BI.

The project explores airline performance, passenger demand, seat utilisation, carrier comparisons and flight route patterns through data analysis and interactive dashboards.

## 🎯 Project Objectives

- Analyse airline operational trends.
- Calculate load factor on yearly, quarterly and monthly bases.
- Compare load factor across airline carriers.
- Identify the top 10 carriers by transported passengers.
- Analyse routes based on flight activity.
- Compare weekday and weekend load factors.
- Analyse flights across different distance groups.
- Examine passenger demand and unused seat capacity.
- Present findings through interactive dashboards.

## 📂 Dataset Description

The main dataset contains airline operational information, including:

- Airline and carrier details
- Origin and destination information
- Year, month and day
- Scheduled and performed departures
- Available seats and transported passengers
- Flight distance
- Freight, mail and operational time fields

Supporting lookup files provide additional airline, aircraft, carrier, region and distance-group information.

The main Excel dataset reviewed contains 110,851 rows and 54 columns.

## 🔄 Project Workflow

1. Understand the dataset and its structure.
2. Prepare and clean the data.
3. Create a date field using year, month and day.
4. Derive month, quarter, weekday and financial-period fields.
5. Calculate load factor using SQL.
6. Analyse carrier and route performance.
7. Compare weekday and weekend load factors.
8. Analyse flight counts by distance group.
9. Build dashboards in Excel, Tableau and Power BI.
10. Summarise the reported results.

## 📊 Key Metrics

**Load Factor (%)**

Total Transported Passengers ÷ Total Available Seats × 100

**Unused Seats**

Total Available Seats − Total Transported Passengers

## 🔍 Key Findings Reported by the Project

- Overall load factor was reported at approximately 76.8%.
- Weekday load factor was reported at 76.73%.
- Weekend load factor was reported at 76.96%.
- Southwest Airlines Co. ranked first in the reported top-carrier passenger analysis, with 34,107,505 transported passengers.
- The under-500-mile distance group recorded 58,047 flights in the analysis workbook.
- January was identified in the presentation as the month with the highest unused seat count.

These results are taken from the existing project materials and should be interpreted using the calculations and definitions applied in the project.
